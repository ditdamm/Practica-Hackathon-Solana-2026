# ◈ Los DataOS

**Gestión financiera colaborativa en un entorno digital conectado con Solana.**

Los DataOS es una plataforma web orientada a facilitar la organización y administración de recursos compartidos. El proyecto busca combinar herramientas de gestión financiera con las posibilidades del ecosistema blockchain.

---

### 🚀 Estado del proyecto

**Prototipo frontend en desarrollo.**

Esta versión presenta la interfaz y la experiencia de usuario mediante datos simulados e interacciones temporales en el navegador.

### 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (ES Modules)

### 📂 Estructura

El proyecto está organizado en módulos independientes para facilitar su mantenimiento y evolución:

- `assets/css/` — Estilos de la aplicación.
- `assets/data/` — Datos de demostración.
- `assets/js/components/` — Componentes visuales.
- `assets/js/core/` — Navegación y gestión del estado.
- `assets/js/modules/` — Secciones de la aplicación.
- `assets/js/services/` — Lógica y operaciones del sistema.

### 💻 Ejecución local

1. Clonar o descargar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar `index.html` mediante la extensión **Live Server**.

### 🔮 Próximas etapas

Integración del backend, conexión con datos reales, persistencia de información y desarrollo de las funcionalidades vinculadas al ecosistema Solana.
